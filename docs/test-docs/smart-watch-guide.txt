SmartWatch X1 产品说明书

一、产品概述
SmartWatch X1 是一款高端智能手表，采用 1.5 英寸 AMOLED 高清屏幕，分辨率为 466×466 像素。表壳采用钛合金材质，重量仅 45 克，支持 IP68 级防水。

二、核心功能
1. 健康监测：支持心率监测、血氧检测、睡眠分析、压力监测。心率监测采用光电容积脉搏波（PPG）技术，精度达到 ±2bpm。
2. 运动模式：内置 100+ 种运动模式，包括跑步、游泳、骑行、登山等。支持 GPS+北斗双模定位。
3. 电池续航：搭载 450mAh 锂电池，正常使用可达 7 天，重度使用 3 天，GPS 运动模式 15 小时。
4. NFC 功能：支持 NFC 公交卡、门禁卡模拟，目前已覆盖全国 300+ 城市。

三、技术参数
- 处理器：骁龙 W5+ Gen 1
- 内存：2GB RAM + 32GB ROM
- 连接：蓝牙 5.2、Wi-Fi 802.11 b/g/n、NFC
- 传感器：加速度计、陀螺仪、气压计、环境光传感器、温度传感器
- 兼容系统：Android 8.0+、iOS 14.0+

四、使用注意事项
1. 首次使用请充电至 100%，充电时间约 1.5 小时
2. 游泳后请用清水冲洗并擦干
3. 避免在极端温度（低于 -10°C 或高于 45°C）环境下使用
4. 心率监测数据仅供参考，不能作为医疗诊断依据
