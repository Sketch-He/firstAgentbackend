# frontend/src/composables 目录说明

## 目录职责

这个目录放前端组合式逻辑，负责管理状态、异步流程和跨组件复用的行为。

## 当前文件

- `useChat.ts`：聊天消息状态、流式发送、错误处理、本地持久化
- `useServiceHealth.ts`：后端健康检查探活

## 当前关键逻辑

1. `useChat.ts` 会将消息列表持久化到浏览器本地存储。
2. 发送消息时，前端通过 SSE 从 `/api/chat/stream` 增量接收助手回复。
3. 在流式过程中，前端会先插入一个空的 assistant 消息，再逐段拼接。
4. 当前已支持停止生成，并保留已经收到的部分回复内容。
5. 当前已支持基于上一轮用户输入的一键重试。

## 协作约定

1. 只要状态结构、持久化方式、流式协议处理方式变化，必须同步更新本文件。
2. 后续 AI 修改对话流时，必须优先检查这里的说明是否仍然准确。
