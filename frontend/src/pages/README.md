# frontend/src/pages 目录说明

## 目录职责

这个目录存放页面级组件，负责把组件、状态和布局组合起来。

## 当前文件

- `ChatPage.vue`: 当前唯一页面，负责承载整套聊天主流程

## 当前关键逻辑

1. 页面本身只组合 `Header`、`MessageList`、`Composer`、`Sidebar` 和 `composables`，不承载复杂请求实现。
2. 页面负责把服务状态、会话列表状态和聊天状态接到展示层。
3. 当前通过版本号防止“快速切换多个会话时旧请求覆盖新结果”的竞态。
4. 桌面端当前由浏览器窗口承担聊天内容滚动，`Sidebar` 保持独立滚动，`Header` 和 `Composer` 通过粘性定位固定在视口内。

## 协作约定

1. 新增页面或页面职责变化时，必须同步更新本文档。
