# frontend/src/components 目录说明

## 目录职责

这个目录放可复用的界面组件，尽量只负责展示和事件抛出，不承载复杂数据请求逻辑。

## 当前组件

- `Header.vue`：页面头部、生成阶段、模型信息、后端服务状态
- `ErrorBanner.vue`：错误提示
- `MessageBubble.vue`：单条消息展示、基础 Markdown 渲染、代码块复制
- `MessageList.vue`：消息列表、流式生成阶段提示、自动滚动到底部
- `Composer.vue`：输入框、发送、停止生成、重试按钮、生成状态提示
- `Sidebar.vue`：会话历史侧栏、新建/切换/删除会话、时间展示

## 设计原则

1. 组件优先接收 `props` 和 `emit`，避免直接耦合远程请求。
2. 状态驱动尽量放在 `composables/` 中。

## 协作约定

1. 新增、删除、重命名组件时，必须同步更新本文件。
2. 如果某个组件开始承担复杂业务职责，也要在这里补充说明。
