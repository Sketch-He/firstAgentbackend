# frontend/src/styles 目录说明

## 目录职责

这个目录存放全局样式和视觉基础定义。

## 当前文件

- `index.css`: 全局样式、布局、组件视觉、Markdown 内容样式、代码块样式、动效

## 当前关键逻辑

1. 桌面端聊天页现在使用浏览器窗口作为主滚动宿主，不再给消息列表单独挂滚动条。
2. 左侧 `Sidebar` 固定在视口内，并通过自身的 `sidebar-list` 维持独立滚动。
3. 聊天区的 `Header` 与 `Composer` 使用粘性定位固定在视口顶部和底部，窗口滚动时只让消息内容穿过中间区域。
4. 输入区仍采用“上方输入块 + 下方工具块”的两段式结构，`textarea` 会在默认高度到 2 倍高度之间自动增长，超出后再显示内部滚动条。

## 协作约定

1. 如果样式拆分为多个文件，或者主题机制、页面滚动策略发生变化，必须同步更新本文档。
