# frontend/src/styles 目录说明

## 目录职责

这个目录存放全局样式和视觉基础定义。

## 当前文件

- `index.css`：全局样式、布局、组件视觉、Markdown 内容样式、代码块样式、动画

## 当前关键逻辑

1. 桌面端页面级滚动默认关闭，避免内容较少时也出现整页滚动条。
2. 当前只允许左侧会话列表和聊天消息列表各自滚动。
3. 聊天输入区固定在聊天面板底部，不跟随消息列表滚动。
4. 输入区当前采用“上方输入块 + 下方工具块”的两段式结构，textarea 会在默认高度到 2 倍高度之间自动增长，超出后再显示内部滚动条。

## 协作约定

1. 如果样式拆分为多个文件，或者主题机制发生变化，必须同步更新本文件。
